# CSVEditorReact

## Overview

This app parses a csv file and creates a table. That table has actions that you can use to edit the table. The resulting table can then be downloaded as a csv.

## Development

Running in web browser: `npm start`

Building for web browser: `npm run build`

Running tests: `npm run test`

Developing as an electron app: `npm run electron`

Building as an electron app: `npm run electron:build`

## Release

You can run this in your web browser using `npm start`, or you can use one of the releases compiled with electron builder.

## Motivation

You're probably reading this and wondering if this is just an excuse to try out React. That is partly true.

 However, there is another reason. During my time at LinkedIn, I worked on various configurations that users could control through uploading CSV files. I found that programs like Excel and Numbers were often overkill for making test csv files, and it was a small pet peeve of mine to wait for those programs to start up. I eventually ended up using TextEdit, but then I was missing some features that I did want. I find that this program fits my preferences much better. Too bad I didn't make this program earlier.
